# 5-minute founder demo script

Use **Phase 1** build with mock data. Pre-load **Dino** case.

## Setup (30 sec)

“This is the document portal we want for every Skilled Worker and ILR case after UKVI submission.”

Open **staff cases** → open **Dino Dominic** draft.

## Beat 1 — Checklist in (45 sec)

1. Show **New case** (or pre-filled review).
2. Point at **UAN** and **route: Skilled Worker** parsed from PDF.
3. “Home Office only asked for passport; our template adds consent, e-visa, share code, partner docs — **nine client uploads**.”

## Beat 2 — Staff review (60 sec)

1. Scroll **slot table** — numbers match OneDrive: `1 Passport Dino`, `7 Sharecode Dino`.
2. Toggle **dependant pack** — partner slots appear (if starting from main-only).
3. Expand **internal guidance** (if Phase 3) or mention it’s staff-only.
4. Click **Publish** → **Copy link**.

## Beat 3 — Client on phone (90 sec)

1. Open link in narrow window / phone emulator.
2. Expand **Before you start** — read share code line: **“To prove an immigration matter.”**
3. Open **Sharecode** slot — show do/don’t + example image.
4. Upload a fake file → **Saved**.
5. Show progress **3/10** — “They can leave and come back.”

## Beat 4 — Finish & staff payoff (45 sec)

1. **Simulate all complete** (demo button) or upload remaining.
2. **Finish** → thank you.
3. Switch to staff **case detail** → **Download zip**.
4. Show filename list matches `Documents/` tree.

## Beat 5 — ILR contrast (60 sec)

Switch demo to **Sophy** case.

- “ILR checklist is long; slots include **absence letter + ticket**, payslip, bank — **cover letter last**, slot 9.”
- Same client UX, different list — proves **config, not rewrite**.

## Close (30 sec)

“Phase 2 wires real uploads and zip. Phase 3 adds every sample image and cover letter preview. No OneDrive API until we’ve piloted.”

**Ask:** green-light Phase 2 pilot on 5 real cases.
