Generate a new share code on GOV.UK and upload a screenshot or PDF showing the full code.

When asked what you need the code for, select **“To prove an immigration matter”** — this is the option to **prove immigration status** for something else. Do **not** select “right to rent” or “right to work”.

The code should have at least **one month** of validity remaining. If you cannot generate a valid code, contact your adviser before uploading.
